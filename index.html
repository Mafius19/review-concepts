Panel de estudio Full Stack Senior: Node, NestJS, Next.js y React — conceptos clave, preguntas de entrevista y reto técnico.

Conceptos core — lo que sí o sí preguntan
Event Loop
Call stack → Web APIs → Callback queue → Microtask queue. Microtasks (Promises, queueMicrotask) tienen prioridad sobre macrotasks (setTimeout, setImmediate).
Worker Threads vs Cluster
Worker Threads para CPU-bound (comparten memoria vía SharedArrayBuffer). Cluster para escalar en múltiples cores duplicando el proceso.
Streams & Backpressure
Readable/Writable/Transform. Backpressure ocurre cuando el consumer no puede seguir el ritmo del producer — manejar con pipe() o highWaterMark.
Módulos ESM vs CJS
CJS: síncrono, require(), caching. ESM: asíncrono, tree-shakeable, import/export. En Node 22+ ESM es el estándar preferido.
Security & hardening
Helmet, rate limiting, validación de input, evitar eval(), actualizar deps con npm audit, usar --experimental-permission en v20+.
Observabilidad
OpenTelemetry nativo. Métricas con process.memoryUsage(), perf_hooks. Profiling con --prof + node --prof-process.
Preguntas frecuentes senior
¿Cómo evitarías bloquear el event loop en una operación CPU-intensiva?
→ Worker threads, offloading a microservicio, caching del resultado costoso.
¿Diferencia entre process.nextTick y Promise.resolve().then?
→ Ambos son microtasks, pero nextTick tiene mayor prioridad dentro del mismo tick.
¿Cómo manejarías memory leaks en producción?
→ Heap snapshots con Chrome DevTools / clinic.js, detectar closures retenidos, event listeners no removidos.

Conceptos core
DI & IoC container
Scopes: DEFAULT (singleton), REQUEST (por request), TRANSIENT (nueva instancia cada vez). Cuidado con REQUEST scope en performance.
Módulos dinámicos
forRoot() / forFeature() / register(). Permiten configurar módulos con opciones en tiempo de arranque (ej: TypeORM, Config).
Auth patterns
JWT con @nestjs/jwt + Guards. Refresh tokens con rotación. RBAC con @Roles() + RolesGuard. Integración con Passport strategies.
Microservicios
Transporters: TCP, Redis, RabbitMQ, Kafka. Patrones: request/response (@MessagePattern) y event-driven (@EventPattern).
Testing
Test.createTestingModule() para unit tests. Mocking de providers con { provide: Service, useValue: mockObj }. E2E con supertest.
ORM & DB patterns
TypeORM con Repository pattern o DataSource directo. Prisma como alternativa type-safe. Migrations en CI/CD, nunca synchronize: true en prod.
Preguntas frecuentes senior
¿Cuándo usarías un Interceptor vs un Middleware?
→ Middleware para transformar req/res antes del routing. Interceptor para transformar la respuesta del handler, logging, caching.
¿Cómo implementarías un sistema de eventos desacoplado en NestJS?
→ EventEmitter2 para eventos in-process, o CQRS con @nestjs/cqrs para separar Commands/Queries/Events.
¿Cómo escalarías un módulo de notificaciones?
→ BullMQ para cola de jobs, patrón productor/consumidor, idempotencia con job IDs.
Rendering strategies — la pregunta de oro
SSG
Build time. generateStaticParams. Ideal: blogs, docs, marketing. Revalidación con ISR (revalidate: N).
SSR
Cada request. export const dynamic = 'force-dynamic'. Ideal: dashboards con datos en tiempo real.
RSC
React Server Components (App Router). Se renderizan en servidor, no se hidratan. Zero JS al cliente. Fetch directo a DB.
Streaming
Suspense + loading.tsx. Envía HTML progresivamente. Mejora TTFB sin sacrificar data fresca.
App Router — conceptos avanzados
Layouts & Templates
Layout persiste estado entre navegaciones. Template re-monta en cada navegación. Parallel routes con @slot. Intercepting routes con (..).
Server Actions
'use server'. Mutaciones directas sin API route. Revalidación con revalidatePath / revalidateTag. Progresivamente mejora forms sin JS.
Middleware & Auth
Corre en Edge Runtime. Proteger rutas antes de renderizar. NextAuth.js / Auth.js v5 para OAuth + JWT + session management.
Optimizaciones
next/image (lazy, WebP, srcset), next/font (self-hosted, no layout shift), next/dynamic (code splitting), Bundle Analyzer.
Preguntas frecuentes senior
¿Cuándo elegirías un Server Component vs Client Component?
→ SC por defecto. CC solo si necesitás hooks, eventos del browser, o estado interactivo. Empujar 'use client' lo más abajo posible en el árbol.
¿Cómo funciona el data cache de Next.js 14+?
→ fetch() extendido con tags y time-based revalidation. Separado del router cache (en memoria, client-side).
Conceptos avanzados que definen el seniority
Concurrent Features
useTransition para marcar updates no urgentes. useDeferredValue para debounce de renders. Suspense para lazy loading y data fetching.
Reconciliation & Fiber
React Fiber: trabajo en unidades interrumpibles. Diffing: mismo tipo = update, distinto tipo = unmount + mount. Keys determinan identidad en listas.
Memoización
useMemo para valores computados costosos. useCallback para estabilizar referencias de funciones. React.memo para componentes puros. No abusar — profiling primero.
State management
Zustand para global simple. Jotai para estado atómico. TanStack Query para server state (cache, refetch, optimistic updates). Context solo para config/tema.
Patrones avanzados
Compound components, Render props, HOC (legacy pero vigente). Custom hooks para lógica reutilizable. Controlled vs Uncontrolled components.
Testing
Testing Library: renderizar, actuar, assertar comportamiento (no implementación). Vitest > Jest en proyectos modernos. MSW para mock de API calls.
Preguntas frecuentes senior
¿Cuál es la diferencia entre useEffect y useLayoutEffect?
→ useLayoutEffect corre síncronamente después del DOM update pero antes del paint — para medir DOM. useEffect es asíncrono, post-paint.
¿Cómo evitarías re-renders innecesarios en una lista de 1000 items?
→ Virtualización (TanStack Virtual), React.memo en items, stable key, selector granular de store.
¿Cómo implementarías un debounce con hooks sin bugs de stale closure?
→ useRef para mantener la función actualizada, useCallback + deps bien declaradas, o librería como use-debounce.
